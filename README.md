# Dragonguard-Score-Manager

Attendee Score Tracker is a lightweight webpage for recording and comparing attendee scores.

## Scores

Each attendee can have a score for:

- 2v2
- 1v1 Score 1
- 1v1 Score 2
- 1v1 Score 3
- FFA

The average includes only scores that have been entered. Use **Copy Filled Format** to copy each attendee's scores and average as text.

## Use the tracker

Open the public site: [Attendee Score Tracker](https://deenisreal.github.io/Dragonguard-Score-Manager/)

Add an attendee, enter any scores, and remove attendees when they are no longer needed. No installation is required.
